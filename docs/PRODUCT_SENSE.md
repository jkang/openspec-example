# 产品感与业务导向 (Product Sense)

本文档旨在为 AI Agent 提供产品设计和业务决策的上下文，确保 AI 生成的代码不仅仅是“能运行的逻辑”，更是“有商业价值的产品”。

## 1. 核心产品理念

- **可视即价值**: 用户感知到的功能才是有效功能。所有后端的改动，必须有对应的前端原型或 UI 体现。
- **克制与聚焦**: 我们正在构建一个 **Minimal E-commerce (极简电商)**。拒绝任何过度设计（Over-engineering），例如复杂的推荐算法、繁琐的积分体系。优先保障核心交易链路（浏览 -> 购物车 -> 结账）。
- **效率优先**: 界面布局强调逻辑驱动，帮助用户以最短路径完成任务，不需要花哨的动画或装饰。

## 2. 目标用户画像 (User Personas)

- **核心买家**: 需要快速定位商品并完成采购。他们对界面的响应速度、数据的真实性和操作的明确性要求极高。
- **系统管理员**: 关注数据的准确性（例如 `priceCents` 的设计），容错性以及订单流转的清晰度。

## 3. AI 决策准则

当 AI 在 `/opsx:explore` 阶段权衡方案，或在 `/opsx:apply` 阶段遇到歧义时，必须遵守以下准则：

1. **如果有两种实现方式，选择对用户最直接的那种。**（例如：直接展示报错信息，而不是用一个模糊的“发生未知错误”）。
2. **拒绝空洞占位符。** 任何时候构建原型，必须代入真实的电商数据（例如：“MacBook Pro 14英寸” 替代 “Test Product A”）。
3. **MVP 原型优先。** 在探索新功能时，优先提供一个可以交互的核心版本（Minimal Viable Prototype），等待人类 (HITL) 反馈确认后，再进行复杂的后端开发。
