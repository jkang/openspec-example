# 技术债追踪 (Tech Debt Tracker)

在快速迭代 MVP 和打通主链路时，我们可能会为了验证业务逻辑做一些架构妥协或硬编码。
AI Agent 在 `/opsx:apply` 阶段为了快速交付而采取的捷径，**必须**记录在此文档中，禁止隐式留存。

## 记录原则

- **不要记录常规 TODO**: 诸如“需要加个新按钮”不属于技术债。
- **只记录架构妥协**: 例如“目前商品库存是写死在内存里的，重启会丢失”、“为了跑通 E2E，暂时绕过了鉴权中间件”。
- **定期清理**: 归档 (Archive) 操作时，应检视是否顺手清理了某些技术债。
