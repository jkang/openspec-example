# 电商运营系统

面向贸易型中小企业的订单-库存-回款一体化运营系统。本术语表统一业务语言，服务需求探索、Story 与领域模型命名。

## Language

**客户 (Customer)**:
下单并完成支付的主体；设置账期后成为信用客户，可在账期内先发货后回款。
_Avoid_: 买家、用户（作为业务角色时）

**运营 (Operator)**:
负责商品、分类、优惠券、订单、用户、库存与渠道配置的角色。
_Avoid_: 管理员、后台

**老板 (Owner)**:
只读查看经营看板、库存健康度与应收账款的角色。
_Avoid_: 管理员、运营

**客服 (Support)**:
协助处理订单与售后事项的角色，不具备运营配置权限。
_Avoid_: 客服人员、售后

**订单 (Order)**:
客户从提交、支付、发货到完成或取消的交易单据，是库存与回款的业务源头。
_Avoid_: 单子、交易

**优惠券 (Coupon)**:
由运营配置、按规则发放、在结算时核销的营销工具。
_Avoid_: 折扣码、券

**应收账款 (Receivable)**:
账期订单发货后形成的待回款金额，按到期日判断是否逾期。
_Avoid_: 欠款、应收

**回款 (Receipt)**:
客户对应收账款的还款登记，支持部分回款与整单结清。
_Avoid_: 收款、还款

**渠道 (Channel)**:
订单来源，当前包括网页与微信小程序。
_Avoid_: 来源、端

**会话 (Session)**:
用户登录后的有效身份上下文，用于订单归属与权限校验。
_Avoid_: 登录态、token
