# High-level Journey 基线

## Purpose
描述用户和运营人员在系统中的端到端核心旅程，作为业务逻辑全景的顶层视图。

## 核心旅程地图

### 1. 买家：从浏览到下单成功
- **Entry**: 进入商城首页
- **Steps**:
  1. 浏览商品目录
  2. 查看商品详情
  3. 加入购物车
  4. 领券与应用优惠
  5. 提交订单并结算
- **Success**: 看到订单成功页面

### 2. 运营：从商品上架到营销配置
- **Entry**: 登录管理后台
- **Steps**:
  1. 发布新商品
  2. 管理库存数量
  3. 配置优惠券规则
  4. 发放优惠券
- **Success**: C 端用户可看到并使用新资源
