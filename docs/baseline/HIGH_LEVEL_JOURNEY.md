# High-level Journey 基线

## Purpose
描述用户和运营人员在系统中的端到端核心旅程，作为业务逻辑全景的顶层视图。

## 核心旅程地图

### 1. 买家：从搜索浏览到结算成功
- **Entry**: 进入商城首页
- **Steps**:
  1. **搜索/浏览**: 使用搜索框过滤或直接浏览商品列表。
  2. **加购**: 选择心仪商品加入购物车。
  3. **结算确认**: 进入结算页，系统自动匹配并应用最优优惠券（满减或折扣）。
  4. **提交订单**: 确认金额（含财务精度补偿）并提交。
  5. **模拟支付**: 完成模拟支付流程。
- **Success**: 跳转至 Checkout Success 页面，显示订单详情。

### 2. 运营：商品与营销闭环
- **Entry**: 登录管理后台
- **Steps**:
  1. **发布管理**: 录入商品信息、设置价格与库存。
  2. **营销配置**: 创建不同类型的优惠券（FLAT/PERCENTAGE）。
  3. **发放控制**: 设定优惠券使用门槛（minSpendCents）。
- **Success**: C 端用户可实时感知商品变更与优惠应用。
