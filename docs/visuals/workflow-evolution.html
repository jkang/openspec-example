Knowledge Asset

OpenSpec 工作流演进全景

从“指令驱动”到“治理驱动”，见证 AI 辅助软件工程如何通过结构化契约与分层治理，彻底解决需求漂移。

1

v1.5 极简版：线性单路闭环

最原始的 SDD 范式，确立了“意图 -> 规格 -> 代码”的流水线。

graph LR E[Explore 探索] --> P[Propose 提案] --> A[Apply 实施] --> S[Sync 同步] --> Ar[Archive 归档] style E fill:#fff,stroke:#64748b,stroke-width:2px style P fill:#fff,stroke:#64748b,stroke-width:2px style A fill:#fff,stroke:#64748b,stroke-width:2px style S fill:#fff,stroke:#64748b,stroke-width:2px style Ar fill:#f1f5f9,stroke:#64748b,stroke-width:2px
核心特征：单向线性流，无复杂任务分支。
适用场景：小型项目，单人开发，需求极度明确。
局限性：缺乏上游治理，难以处理复杂的 UI 交互与业务规则。
