# Story: 商品分类管理 (story-product-category)

## 用户场景

- **目标用户**: 电商运营人员（B 端）与买家（C 端）。
- **使用动机**: 运营需要结构化组织商品目录（按品类维护分类、给商品挂分类）；买家需要按品类浏览/筛选商品，快速定位目标品类，而非翻全量列表。
- **关键目标**: 补齐 Phase 2 In Scope「商品分类管理」，形成「运营配置分类 → 商品挂分类 → C 端按分类浏览」闭环。

## 范围

### In Scope

- **分类 CRUD（B 端）**：新增/编辑/删除（软删除）分类：名称、排序号；删除时该分类商品 `categoryId` 置空。
- **商品挂分类**：商品编辑表单增加「分类」下拉（可空 = 未分类）。
- **C 端分类筛选**：首页商品区顶部分类筛选条（「全部」+ active 分类），与关键词搜索/价格排序组合。
- **接口**：`GET/POST/PUT/DELETE /api/categories`（软删除）；`GET /api/products?categoryId=` 过滤。

### Out of Scope

- 多级分类树、分类图片/图标。
- 批量移动商品分类、分类排序拖拽（仅数字排序）。
- Python 后端同步实现（本次观察）。
- 分类维度报表。

## 业务规则

| 规则ID | 规则描述 | 触发条件 | 期望结果 | 备注 |
| --- | --- | --- | --- | --- |
| R-CAT-001 | 分类必填名称 | 提交分类 | 名称非空，否则拒绝 | 排序号缺省 0 |
| R-CAT-002 | 分类唯一性 | 新增/编辑分类 | 同名分类拒绝创建 | 防重复（名称精确匹配） |
| R-CAT-003 | 软删除分类 | 运营删除分类 | status 置 deleted，列表/筛选移除 | 非物理删除 |
| R-CAT-004 | 删除清空关联 | 删除分类 | 该分类下所有商品 categoryId 置空（未分类） | 不影响可售与历史订单（快照） |
| R-CAT-005 | 商品挂分类可选 | 编辑商品 | categoryId 可空 = 未分类 | 存量商品兼容 |
| R-CAT-006 | C 端过滤 | 买家点击分类 | 商品列表按 categoryId 过滤，仅 active 商品 | 与搜索/排序组合 |
| R-CAT-007 | 分类列表活性 | C 端/后台拉取分类 | 仅返回 status=active 分类，按 sortOrder 排序 | — |

## 验收标准 (E2E 用户旅程)

### 旅程 1：运营维护分类

- **流程映射**: `L1-01` 触达与发现（分类供给）；`SB-STAGE-01`、`SB-OPS-01`、`SB-BACKSTAGE-01`

#### 场景：新增分类并出现在列表

- **GIVEN** 运营人员王琳登录运营后台并进入「交易管理 / 分类管理」
- **WHEN** 王琳填写分类名称「键鼠外设」、排序号 1，并点击「新增分类」
- **THEN** 分类列表新增该分类，状态为「生效中」
- **AND** C 端首页分类筛选条出现「键鼠外设」

#### 场景：删除分类后商品置空

- **GIVEN** 分类「音频设备」下存在商品「桌面拾音氛围灯」
- **WHEN** 王琳删除「音频设备」并确认
- **THEN** 该分类从分类列表与 C 端筛选条移除
- **AND** 「桌面拾音氛围灯」的分类变为「未分类」，仍正常在售

#### 场景：同名分类被拒绝

- **GIVEN** 已存在分类「键鼠外设」
- **WHEN** 王琳再次新增名称「键鼠外设」
- **THEN** 系统拒绝并提示「分类名称已存在」

### 旅程 2：商品挂分类

- **流程映射**: `L1-01`、`L1-02`（商品元数据）；`SB-OPS-01`、`SB-BACKSTAGE-01`

#### 场景：编辑商品分类

- **GIVEN** 商品「极简机械键盘」当前未分类
- **WHEN** 王琳在商品编辑中选择分类「键鼠外设」并保存
- **THEN** 该商品分类显示为「键鼠外设」
- **AND** 「键鼠外设」的商品数 +1

### 旅程 3：C 端按分类浏览

- **流程映射**: `L1-01` 触达与发现；`SB-STAGE-01`、`SB-CUSTOMER-01`

#### 场景：按分类筛选商品

- **GIVEN** 买家打开 C 端首页，分类筛选条显示「全部 / 键鼠外设 / 显示设备 / 桌面收纳 / 音频设备」
- **WHEN** 买家点击「键鼠外设」
- **THEN** 商品列表仅展示分类为「键鼠外设」的 active 商品（极简机械键盘、无线办公鼠标）
- **AND** 点击「全部」恢复全量商品

#### 场景：分类筛选与关键词搜索组合

- **GIVEN** 买家已选择「桌面收纳」分类
- **WHEN** 买家在搜索框输入「支架」
- **THEN** 商品列表仅展示「桌面收纳」分类下名称含「支架」的商品（铝合金笔记本支架）
