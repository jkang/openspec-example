# PPT 内容页配色要求（Content-Page Color Spec）

> 来源：**附图 2** — AI+ 研发数字峰会 · NiDD City Lab | 成都站 收尾页（THANKS / 扫码领取会议PPT资料）
> 用途：把该封面/收尾页的品牌配色，**迁移到任意内容页**（信息密度高、含流程、看板、表格的页面）。
> 产出 token：`assets/palette.nidd-citylab.json`（可直接 `build_slide.py --palette` 消费）

---

## 1. 源图配色解读

源图是一张"收尾页"，画面元素极简，配色由 **绿 + 蓝 + 极浅绿白底 + 近黑字** 四层构成：

| 观察对象 | 颜色角色 | 解读 |
| :--- | :--- | :--- |
| `THANKS` 主标题、Logo 的 `N`、熊猫/建筑主体 | **品牌绿** | 面积最大、饱和度最高的彩色，是品牌主色 |
| Logo 的 `DD`、贯穿画面的蓝色曲线 | **品牌蓝** | 少量但高对比，承担"动线 / 连接 / 科技感" |
| 整页背景 | **极浅绿白** | 不是纯白，带 ~2% 绿味的暖白，降低屏幕刺眼度 |
| 峰会名称、说明文案 | **近黑墨色** | 中性偏冷，不用纯黑，保证长文可读 |
| 3D 立体阴影 | **中性灰** | 仅作体积感，不承担语义 |

**关键结论**：源图是 **双主色（绿 + 蓝）+ 单一中性底** 的结构，**全程没有暖色**（无红/橙/紫/黄）。内容页必须继承这个约束，否则会立刻"串味"。

## 2. 色板 Token

### 2.1 核心色

| Token | HEX | 说明 |
| :--- | :--- | :--- |
| `bg` | `#F6F8F3` | 页面底色（极浅绿白） |
| `white` | `#FFFFFF` | 卡片 / 面板底色 |
| `ink` | `#1F2933` | 正文墨色 |
| `green` | `#4CAF50` | 品牌主色 |
| `green_dark` | `#2E7D32` | 主色深阶（文字 / 强调） |
| `blue` | `#2E5CE6` | 品牌副色（焦点 / 动线） |
| `blue_dark` | `#1B3FA0` | 副色深阶（文字） |

### 2.2 中性 / 分隔

| Token | HEX | 说明 |
| :--- | :--- | :--- |
| `slate` | `#3F4A52` | 深中性（"过去/负向"容器底） |
| `slate_light` | `#6B7280` | 次级文字 |
| `gray_mid` | `#9AA3A8` | 弱化文字 / 占位 |
| `gray_soft` | `#F1F3F5` | 弱化填充 |
| `border` | `#E3E8E0` | 描边（带一点绿味的灰，不是冷灰） |

### 2.3 浅色底（面板 / 表头 / 标签）

| Token | HEX | 用途 |
| :--- | :--- | :--- |
| `green_soft` | `#E8F5E9` | 绿色系面板底 |
| `green_tint` | `#DFF0E2` | 绿色系更浅一档 |
| `blue_soft` | `#E9EEFC` | 蓝色系面板底（焦点列） |
| `blue_tint` | `#EDF1FD` | 蓝色系更浅一档 |
| `board_bg` | `#F7F9F4` | 大容器底（比卡片白略深） |

### 2.4 成熟度色阶（L0 → L5）

用于"自动化能力水平"这类**有序等级**，必须是**灰 → 绿的单向渐变**，不允许跳色：

| 等级 | HEX | 含义 |
| :--- | :--- | :--- |
| L0 | `#9AA3A8` | 纯手工（灰） |
| L1 | `#8FB89A` | 辅助编程 |
| L2 | `#6FAF84` | 部分自动化 |
| L3 | `#4FA46C` | 有条件自动化 |
| L4 | `#379455` | 高度自动化 |
| L5 | `#2E7D32` | 完全自动化（最深绿） |

> 色阶只在**同一语义维度**内使用；不要拿 L3 的绿去当"成功"色。

## 3. 语义约定（最重要）

**一个颜色只表达一个含义。** 本套色板的语义分工：

| 颜色 | 语义 | 出现位置 |
| :--- | :--- | :--- |
| 🟩 **绿** | 自动化成熟度 / 价值 / 达成 | 流程中后段、正向看板、已上线 |
| 🟦 **蓝** | 焦点 / 瓶颈 / 待改进 / 动线 | 标题强调短语、瓶颈节点、问题提示条、"现在"看板 |
| ⬜ **浅绿白** | 中性底 | 页面底色、容器底 |
| ⬛ **墨/深板岩** | 事实陈述 / "过去"的沉重感 | 正文、"过去"看板容器 |
| ⬜ **灰** | 弱化 / 占位 / 手工态 | `…` 占位卡、L0-L1、次级说明 |

**反向约束**：
- 不要用绿色表示"问题"——问题是蓝色的事。
- 不要用蓝色表示"成熟"——成熟是绿色的事。
- 不要引入红色表示"严重"，用 `slate` 深底 + 白字表达"沉重"。

---

## 4. 面积比例：60 / 30 / 10

| 占比 | 内容 |
| :--- | :--- |
| **60%** 中性 | `bg` + `white` + `gray_soft`（页面底、卡片、容器） |
| **30%** 主色 | `green` 家族（流程卡色条、等级徽章、正向看板列头） |
| **10%** 副色 | `blue` 家族（标题强调、瓶颈标记、问题提示条） |

> 内容页天然信息密度高，**彩色只用于"编码信息"**，绝不用于装饰。装饰性色块一律砍掉。

---

## 5. 文字与对比度规则

| 场景 | 规则 |
| :--- | :--- |
| 正文 | `ink` on `bg` / `white` / 浅色底 —— 对比度 ≥ 10:1 |
| 彩色底 | **只用白字**（`white` on `green_dark` / `blue` / `slate`） |
| 浅色底 | 用对应的深阶（`blue_soft` 底 → `blue_dark` 字；`green_soft` 底 → `green_dark` 字） |
| 次级说明 | `slate_light`，**最小 6pt**，且不承载关键信息 |
| 弱化/占位 | `gray_mid`，仅用于 `…` 等占位 |
| 描边 | `border` 0.75pt；强调描边用语义色 1.5pt |

**禁止**：浅底浅字（如 `gray_mid` on `bg`）、彩色底上放深色字。

---

## 6. 组件级配色规范

| 组件 | 底色 | 文字 | 描边 |
| :--- | :--- | :--- | :--- |
| 页面 | `bg` | `ink` | — |
| 大容器（看板） | `board_bg` | `ink` | `border` |
| 卡片 | `white` | `ink` | `border` |
| 流程卡（普通） | `white` | `ink` | `border` |
| 流程卡（瓶颈） | `white` | `blue`（标题） | `blue` 1.5pt |
| 流程卡（终态/目标） | `green_dark` | `white` | `green_dark` |
| 列头（中性） | `gray_soft` | `slate` | — |
| 列头（焦点） | `blue_soft` | `blue_dark` | — |
| 列头（正向） | `green_soft` / `green_tint` | `green_dark` | — |
| 等级徽章 | 对应 L 色 | `white` | — |
| 提示条（负向） | `slate` | `white` | — |
| 提示条（焦点） | `blue` | `white` | — |
| 看板标题条 | `slate → slate_light` 或 `blue → green_mid` 渐变 | `white` | — |

**渐变**：只允许出现在"看板标题条"这一处（蓝→绿，呼应源图的蓝色动线）。其余一律纯色。

## 7. 字体与字重（配套要求）

> **硬约束：任何可见文字 ≥ 10pt。** 由 `build_slide.py` 的 `MIN_PT` 统一强制，
> `--check` 会逐 run 扫描。装不下就砍内容，不要缩字号。

| 元素 | 字号 | 字重 |
| :--- | :--- | :--- |
| 页面主标题 | 26–28pt | Bold |
| 副标题 | 11pt | Regular |
| 区块标题（看板标题 / 团队名） | 14–19pt | Bold |
| 主体正文 | 10.5–11.5pt | Regular |
| 列头 / 注释 / 标签 / 页脚 | **10pt（下限）** | Bold / Regular |
| 数字强调（柱状图数值） | 16pt | Bold |
| 等级徽章 / 小标签 | 10pt | Bold |

字体族：中文 **PingFang SC**（macOS）/ 微软雅黑（Windows）；通过 `SLIDE_FONT` 环境变量切换。

### 配套的密度预算

10pt 下限意味着单页能装的信息有限，必须同时限制条目数：

| 约束 | 值 |
| :--- | :--- |
| 单页文字层级 | ≤ 3 层 |
| 单个列表项 | ≤ 4 条 |
| 单列文字块 | ≤ 2 个 |
| 单个文本块 | ≤ 3 行 |
| 表格单元格 | ≤ 12 字 |

**违反预算时的处理顺序**：① 删掉重复表达 → ② 把次要信息降级到注释 →
③ 拆成两页。**永远不要把字号调到 10pt 以下。**

---

## 8. 禁止事项（Anti-patterns）

1. ❌ 引入暖色（红 / 橙 / 黄 / 紫）——源图没有。
2. ❌ 标题下方加装饰性横线（AI 生成感最强的一种）。
3. ❌ 给同一语义换第二种颜色（"问题"一会儿蓝一会儿红）。
4. ❌ 彩色等面积堆叠（绿蓝五五开）——必须保持 60/30/10。
5. ❌ 使用阴影（源图只有 3D 元素的物理阴影，平面 UI 不用）。
6. ❌ 圆角不统一（本规范统一：容器 0.10" / 卡片 0.05" / 胶囊 0.5×高度）。
