# 访谈记录归位（三源合并）

## 用途

把一场访谈的三份材料合并成一份**可核对、可溯源的事实稿**，内嵌进 `research.md` 的「访谈原始记录」。只归位事实，不做提炼、推断、评价。

## 三源分工

| 输入 | 作用 |
| --- | --- |
| 访谈提纲 | 提供骨架与题号，作为输出结构 |
| 人工记录 | 现场关键词打底，标出每题已有信息 |
| AI 录音转写 | 补细节、补数字、摘原话 |

归位逻辑：**提纲为骨架，人工记录打底，录音补全**。

## 硬规则

1. **只做事实归位**：记录受访者所述；区分「应该这样」与「实际这样」。
2. **未提及必须显式标注**：未答/未问写「未提及」/「本次访谈未涉及」，留空等于臆造。
3. **转写错误两级处理**：
   - 明显错别字/误词 → 直接纠正；
   - 专有名词无法确证 → 保留原词并进「待澄清」清单。
4. **不做分析**：不产出问题定义、机会地图、流程结论。
5. **内嵌不独立**：归位结果写入 `research.md` 对应章节，不新建独立文件。

## 输出结构

按提纲逐题归位；无提纲时按业务链路归位。每条至少包含：
- 对象与场景
- 受访者所述事实（原话优先）
- 数字/口径
- 未提及项
- 待澄清项

## 完成判据

- 三份材料中的事实均已归位，无遗漏题号；
- 未提及项与待澄清项显式列出；
- 业务方可逐条核对。
